Discover community-maintained registries for shadcn-vue components, blocks, and more. These are built into the CLI — install any item with `npx shadcn-vue@latest add @<registry>/<item>`, no extra configuration required.

::callout{type="warning"}
Community registries are maintained by third-party developers. Always review code on installation to ensure it meets your security and quality standards.
