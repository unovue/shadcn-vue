These registries are built into the CLI with no additional configuration required. To add a component, run: `npx shadcn-vue@latest add @<registry>/<component>`.

::callout{class="bg-muted font-semibold"}
Community registries are maintained by third-party developers. Always review code on installation to ensure it meets your security and quality standards.
::

Don't see a registry? Learn how to [add it here](/docs/registry/getting-started).

::registry-directory
::

## Documentation

You can use the `shadcn-vue` CLI to run your own code registry. Running your own registry allows you to distribute your custom components, hooks, pages, config, rules and other files to any project.
